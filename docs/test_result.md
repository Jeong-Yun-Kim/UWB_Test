## 6. 100회 연속 시험

수신 프로그램을 먼저 실행한 다음 송신 측에서 다음 명령으로 정확히 100개를 보낸다.

```bash
python3 sender.py --count 100
```

| 측정값 | 결과 |
|---|---|
| 송신 개수 | 100 |
| 수신 총개수 | 미실행 |
| 고유 순번 수 | 미실행 |
| 중복 순번 | 미실행 |
| 누락 순번 | 미실행 |
| 순서 역전 | 미실행 |
| 손실률 | 미실행 |

손실률 계산식:

```text
손실률(%) = (100 - 수신한 고유 순번 수) / 100 × 100
```

`[UWB SENT]`는 송신 측 DW1000의 로컬 송신 완료일 뿐 수신 성공 ACK가 아니다. 최종 성공 여부와 손실률은 Jetson 수신 로그를 기준으로 판단한다.

## 7. 지연 시간에 대한 제한

현재 구성은 단방향이며 Jetson과 Basecamp의 시계 동기화 및 역방향 ACK가 없다. 따라서 이 코드만으로 정확한 종단간 평균 지연 시간은 측정할 수 없다. 실제 지연 측정은 다음 단계에서 NTP/PTP 시계 동기화 또는 왕복 ACK 중 하나를 추가한 뒤 별도 수행한다.
